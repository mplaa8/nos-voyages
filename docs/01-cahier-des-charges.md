Application d’anniversaire — « Joyeux anniversaire mon amour »

1. Concept général

Je souhaite créer une petite application personnalisée pour l’anniversaire de ma femme.

L’objectif est de lui offrir une expérience interactive et personnelle autour de nos voyages et des souvenirs que nous avons construits ensemble.

L’application doit être utilisable gratuitement et être optimisée pour un iPhone.

Deux solutions sont envisagées :

* une application iOS installable sur iPhone ;
* ou, de préférence si cela permet de rester entièrement gratuit, une web app adaptée à l’iPhone, accessible depuis un navigateur et pouvant éventuellement être ajoutée à l’écran d’accueil de l’iPhone.

2. Écran d’accueil

Lorsqu’elle ouvre l’application, elle doit arriver sur une page d’accueil simple, élégante et romantique.

Le message principal doit être :

« Joyeux anniversaire mon amour ❤️ »

Cette page peut éventuellement contenir une courte animation ou un élément visuel permettant de créer un effet « cadeau » lors de l’ouverture.

3. Carte interactive du monde

La fonctionnalité principale de l’application est une carte interactive du monde.

La carte doit permettre de :

* naviguer librement dans le monde ;
* zoomer et dézoomer ;
* sélectionner les différents pays.

Pays déjà visités

Les pays que nous avons visités ensemble doivent être clairement mis en évidence.

Par exemple :

* couleur plus vive ;
* couleur différente ;
* luminosité plus importante ;
* ou tout autre système permettant de les distinguer immédiatement.

L’objectif est qu’en regardant la carte, on puisse visualiser rapidement tous les endroits du monde que nous avons déjà découverts ensemble.

Pays non visités

Les pays que nous n’avons pas encore visités doivent rester visibles, mais être représentés de manière plus neutre ou discrète.

Par exemple :

* couleur grise ;
* faible luminosité ;
* couleur désaturée.

Cela permettra de créer un contraste entre :
« les endroits où nous sommes déjà allés » et « les endroits qu’il nous reste à découvrir ».

4. Fiche de chaque pays

Lorsque l’on sélectionne un pays, une fiche dédiée doit s’ouvrir.

Pour chaque pays, je souhaite pouvoir enregistrer nos souvenirs.

La fiche peut notamment contenir :

📸 Photos

* Ajouter une ou plusieurs photos ;
* Consulter les photos associées au pays ;
* Supprimer des photos ;
* Éventuellement afficher les photos sous forme de galerie.

💬 Souvenirs et commentaires

Pouvoir écrire des commentaires ou des souvenirs associés au pays.

Par exemple :

* raconter un souvenir particulier ;
* noter une anecdote ;
* écrire une phrase personnelle ;
* indiquer ce que nous avons aimé ;
* noter les villes ou endroits visités.

Il doit être possible de :

* ajouter un commentaire ;
* modifier un commentaire ;
* supprimer un commentaire.

5. Application évolutive

L’application ne doit pas être figée.

Je souhaite pouvoir la faire évoluer au fil du temps.

Il doit donc être possible de :

* ajouter un nouveau pays visité ;
* retirer un pays si nécessaire ;
* ajouter des photos ;
* supprimer des photos ;
* ajouter des souvenirs ;
* modifier des souvenirs ;
* supprimer des souvenirs ;
* modifier les informations associées à un pays.

L’objectif est que l’application puisse devenir notre carnet de voyage numérique personnel, et continuer à vivre après l’anniversaire.

6. Gestion des données

Les données doivent idéalement être conservées de manière persistante afin de ne pas être perdues lorsque l’application est fermée.

Il faut donc prévoir un système permettant de sauvegarder :

* les pays visités ;
* les photos ;
* les commentaires et souvenirs ;
* les éventuelles autres informations associées aux voyages.

Une interface d’administration simple pourrait permettre à moi seul de modifier le contenu de l’application.

L’expérience de ma femme doit rester très simple : elle consulte et découvre les souvenirs, tandis que je peux gérer le contenu.

7. Contraintes techniques

La contrainte principale est de réaliser le projet avec uniquement des solutions gratuites, autant que possible.

Je souhaite éviter :

* les services payants ;
* les abonnements ;
* les API nécessitant une clé payante ;
* les hébergements payants ;
* les bases de données payantes.

La solution devra donc privilégier des technologies et services disposant d’une offre gratuite suffisante pour ce projet personnel.

8. Priorité : expérience sur iPhone

L’application doit être pensée en priorité pour un écran d’iPhone.

Elle doit donc :

* être responsive ;
* être agréable à utiliser au tactile ;
* avoir des boutons suffisamment grands ;
* permettre une navigation fluide sur la carte ;
* fonctionner correctement sur Safari iPhone ;
* idéalement pouvoir être ajoutée à l’écran d’accueil comme une application grâce aux fonctionnalités d’une Progressive Web App (PWA).

9. Expérience utilisateur souhaitée

L’expérience doit être avant tout :

romantique → personnelle → visuelle → interactive → simple.

L’idée n’est pas de créer une application complexe, mais plutôt une carte interactive de notre histoire et de nos voyages.

Lorsqu’elle ouvre l’application, elle doit immédiatement comprendre :

« Cette application raconte tous les endroits que nous avons découverts ensemble. »

Puis elle peut explorer la carte, cliquer sur les pays et retrouver les photos et les souvenirs associés.

10. Vision à terme

À terme, l’application pourrait devenir une sorte de :

« Carte de nos voyages » ❤️

avec :

* les pays déjà visités ;
* nos photos ;
* nos souvenirs ;
* nos anecdotes ;
* et éventuellement les futurs voyages à venir.

Chaque nouveau voyage pourrait ainsi être ajouté à notre carte au fil des années.
